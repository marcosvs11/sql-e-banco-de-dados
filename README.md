# SQL e Bancos de Dados

Repositório para acompanhar meus estudos de SQL e bancos de dados relacionais, da introdução aos fundamentos até a aplicação desses conhecimentos em projetos de backend.

## Objetivo

Quero entender como os dados são organizados, relacionados e consultados em bancos relacionais. Ao longo do percurso, pretendo desenvolver autonomia para:

- explicar os conceitos estudados com minhas próprias palavras;
- escrever consultas e interpretar seus resultados;
- identificar e corrigir erros;
- adaptar o que aprendi a novos exercícios e problemas;
- aplicar SQL em projetos de backend com Java quando tiver construído a base necessária.

Concluir uma aula ou executar uma consulta com ajuda não significa, por si só, que domino o assunto. O progresso será registrado pelo que consigo explicar e fazer com autonomia.

## Trilha principal

A trilha principal será o curso **Relational Databases**, da freeCodeCamp. O curso orienta a sequência inicial; anotações e exercícios próprios servirão para revisar e praticar o que for estudado.

Quando uma sintaxe ou comportamento depender de um sistema específico — por exemplo, PostgreSQL — isso será identificado nos registros. Não vou tratar uma característica de uma ferramenta como regra universal de SQL.

## Como vou acompanhar o progresso

Para cada assunto, vou distinguir:

- **Estudado:** assisti à aula ou consultei o material.
- **Praticado com ajuda:** fiz exercícios com pistas, explicações ou consultas de referência.
- **Aplicado com autonomia:** consegui explicar e usar o conceito sem depender de uma solução pronta.
- **Revisar:** ainda tenho dúvidas ou preciso praticar mais.

Essas categorias descrevem meu aprendizado; não são uma certificação de domínio.

## Organização

A estrutura será ampliada conforme o curso e os estudos avançarem. A ideia inicial é manter:

- anotações curtas sobre os conceitos;
- consultas e exercícios que eu realmente pratiquei;
- projetos pequenos para aplicar os fundamentos;
- referências consultadas quando forem úteis para compreender ou confirmar um ponto.

Não vou criar pastas para conteúdos que ainda não estudei. A integração com Java e JDBC ficará para uma etapa posterior, depois de uma base suficiente em SQL e Java.
